# 📱 KasperLingo

**Переводчик английских слов на русский язык** с сохранением истории и избранного.

## 🌟 Описание

KasperLingo - это простое и удобное Android приложение для перевода слов с английского на русский язык. Приложение использует API Skyeng для получения переводов и сохраняет историю переводов локально.

### ✨ Основные функции:
- 🔍 **Перевод слов** с английского на русский
- 📚 **История переводов** на главном экране
- ⭐ **Избранное** - сохранение важных переводов
- 💾 **Offline доступ** к сохраненным переводам
- 🎨 **Material Design** интерфейс

## 🚀 Возможности

- **Быстрый поиск** - введите слово и получите перевод
- **История переводов** - все переводы сохраняются автоматически  
- **Избранное** - добавляйте важные слова одним нажатием
- **Кэширование** - переводы доступны без интернета
- **Красивый UI** - современный дизайн Material 3

## 🔧 Установка и запуск

### Требования:
- **Android Studio** Hedgehog или новее
- **Android SDK 35**
- **JDK 11**
- **Kotlin 2.0+**

### Шаги установки:

1. **Клонировать репозиторий:**
```bash
git clone <repository-url>
cd KasperLingo
```

2. **Открыть в Android Studio:**
   - File → Open → выбрать папку проекта

3. **Синхронизировать Gradle:**
   - Android Studio автоматически предложит синхронизацию

4. **Запустить приложение:**
   - Подключить устройство или запустить эмулятор
   - Нажать Run (▶️) в Android Studio

## 📚 API

Приложение использует **Skyeng Dictionary API**:
- **Endpoint**: `https://dictionary.skyeng.ru/api/public/v1/words/search`
- **Документация**: https://dictionary.skyeng.ru/doc/api/external
- **Авторизация**: не требуется (публичный API)

## 🎯 Функциональность

### Главный экран:
- ✅ Поиск переводов английских слов
- ✅ История всех переводов
- ✅ Добавление в избранное
- ✅ Удаление из истории

### Экран избранного:  
- ✅ Список сохраненных переводов
- ✅ Счетчик количества слов
- ✅ Удаление из избранного
- ✅ Навигация назад

### Дополнительно:
- ✅ Кэширование переводов (30 минут)
- ✅ Retry логика для сетевых запросов
- ✅ Обработка ошибок подключения
- ✅ Loading состояния

## 💡 Архитектурные решения

- **Clean Architecture** - четкое разделение ответственностей
- **MVVM** - реактивное управление UI состоянием  
- **Single Source of Truth** - Room как единственный источник данных
- **Offline First** - кэширование для работы без сети
